# 確認範囲

## 実行した確認

- Node.js 24.19.0 / Astro 7.4.0 / GSAP 3.15.0で依存関係をインストール。
- JavaScriptの構文チェック。
- 9件の自動テスト。6種類の画面寸法で、初期見出しが用紙上に収まること、最大紙送り後にもローラー下に用紙が残ることを確認。
- 紙送りとノブ回転の比例関係、逆スクロール時の復帰、指定文言を保つ改行、元SVGとのレイヤー対応を確認。
- ルート配置用と `/about/` 配置用の静的ビルド。
- 両ビルドのJavaScript・faviconの参照先とcanonical URLを検査。
- SVGを描画して、デスクトップとスマートフォンの初期位置・紙送り途中の重なりを確認。

## 未確認の範囲

この制作環境では対応するブラウザ操作機能を利用できなかったため、実ブラウザ上のホイール・タッチスクロール、GSAPのpin処理、OSの動きを減らす設定の切替は実操作で確認していません。SVGの描画と自動テストは、ブラウザでの確認を置き換えるものではありません。

公開前に `npm run dev` で、PCでのスクロール、スマートフォンでの表示、画面の縦横切替、先頭へ戻る操作を確認してください。
