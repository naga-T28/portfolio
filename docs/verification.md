# 検証記録

確認日：2026-10-16（Asia/Tokyo）。Node.js 24.14.1 / Astro 7.4.0 / GSAP 3.15.0。ブラウザのバージョンと詳細結果は [browser-results.json](browser-results.json) に保存しています。

## 自動テスト

`npm run check`：JavaScript構文チェックと **16件すべて成功**。

- 各文字の出現時点で、活字の中心が文字セルの中心に一致。
- 紙上の文字y座標 + 紙送り量 = 印字ライン（y=686）。
- 紙のx移動は0。打鍵で右送り、改行で左端復帰と1行の上送り。
- 紙送り距離とローラー回転角が半径31に対して一致。
- 途中・末尾・先頭の任意シークで同じ部品状態に復帰。
- 全角ピッチ、見出し、箇条書き、罫線、禁則、長いURL、空の本文。
- 14個のSVGに、可動部ID・必要なpaint serverが存在。ID重複なし。
- 新しい素材に紙・文字の焼き込み、`image`、ラスタdata URLなし。

## 実ブラウザでの自動操作

PlaywrightからローカルChromeを起動し、開発サーバーを操作しました。

- 7箇所の打鍵をサンプリングし、**ヘッド中心と文字セル中心／文字セル下端と印字ラインの誤差が0.08 CSS px未満**であることを計測。
- 改行前後で紙と印字済み文字の移動量が同一、ノブ回転が変化することを確認。
- 進行度13%、24%、51%、78%、100%の正逆シークで、文字数・キー・活字・紙・ノブのDOM状態が一致。
- 改行70%の途中に戻して停止しても、同じ状態を再現。
- 先頭まで戻すと初期状態へ復帰。
- 320×740、375×812、390×844、414×896、768×1024、844×390、1280×720を順にリサイズ。水平オーバーフローなし、文字とヘッドの一致を確認。
- 599pxの境界を跨ぐリサイズでフォントサイズ・組版が更新されることを確認。
- reduced-motionを途中で有効にするとstickyとスクロール距離が解除され、全文表示。戻すと再び画面に固定される。
- 「演出 OFF」で静止文書に切り替え、「演出 ON」でタイプライターに戻る。
- JavaScript無効でも全文を表示。
- ブラウザの実行時エラーなし。

## ビルドと配布

`npm run package` でルート配置用と `/about/` 配置用の両方をビルドし、ソース・素材・ドキュメント・テスト・設定・lockfileを `release/` に収録します。旧SVGは配布物に含めません。

## 確認範囲の限界

実ブラウザの検証はmacOS版Chromeの自動スクロール・画面サイズ変更です。iOS Safari / Android実機のタッチ操作、各OSのフォント差は未確認です。描画サイズを縮小する小画面では「演出 OFF」で通常サイズの全文を読めます。
