# 動きの設計

## 紙が本体から送り出される構造

`#paper-feed` の中に、紙本体・紙の端・`#preprinted-content`・`#print-content` が入っています。この親グループだけをY方向に移動するため、印字された文字が紙面を滑りません。

用紙はプラテンの位置（SVGのy=703）でクリップされます。画面に見えない下側にも十分な長さの紙を用意し、送り出してもローラー付近に隙間が開かないようにしています。

用紙の左右端は `src/scripts/motion.js` の `PAPER`（上端 x=410〜1190、プラテン位置 x=395〜1205）で定義しています。幅を変える場合は、SVG内の `paper-wrap-shading` と `tw-printable` のクリップも合わせて調整してください。

タイプライター本体は画面下端に固定しています。SVGのy≈1290（脚と底面のすぐ下）がステージ下端に来るよう、CSSの `bottom` を本体幅の -110/1600 にしています。

本体は固定し、キャリッジ（プラテン・紙・改行レバーを含む）は打鍵に合わせて左右に動きます。紙が曲がって暗くなる部分 `#paper-wrap-shading` は、紙の子ではなくキャリッジ側に置いています。そのため、紙送り後も陰影はローラーの近くに残ります。

## 打鍵の振り付け

`src/scripts/motion.js` の `buildScript` が本文を折り返し、打鍵・スペース・改行の時系列を作ります。`frameAt(progress)` は進捗0〜1に対する全部品の姿勢を返す純粋関数です。そのため、逆スクロールでは同じ動きを逆再生します。

ScrollTriggerがステージをpinし、スクロール量を進捗に変換します。スクロール距離は「打鍵数 × `scrollPerStroke`」で、改行は3.2打鍵分、スペースは0.75打鍵分です。

| 動作 | 部品 | 動き |
|---|---|---|
| 文字キー | `key-*` | 7沈んで戻る。大文字は反対の手側の `key-shift-*` を先に押し、最後に離す |
| 印字 | `typebar-action` | 支点(800,867)でY縮尺 0.12→1。加速して打ち、打った瞬間に文字が紙に付く |
| エスケープメント | `carriage` | キーが戻るときに1文字分左へ。紙はキャリッジの子なので一緒に動く |
| リボン | `ribbon-spool-*-rotor` | 1打鍵ごとに4°回転 |
| スペース | `spacebar` | 6沈み、キャリッジだけ進む |
| 改行 | `carriage-return` → `paper-feed` → `carriage` | レバーを16°倒し、プラテンが1行分回って紙を送り、キャリッジが行頭へ戻る |

文字は `#print-content` の中に1文字ずつ `<text>` で置きます。位置は打鍵した瞬間のキャリッジと紙の位置から逆算するので、本体座標では常に印字位置 `(800,686)` で打たれます。濃さと位置には、決まった値の小さなばらつきを付けています。

welcomeは「打ち終えた直後」として、印字位置の2行上に置きます。紙の上端はwelcomeの約1インチ（92）上です。打鍵が進むにつれて紙が本体から送り出されます。

`prefers-reduced-motion: reduce` の場合はpinを使わず、打ち終えた紙面を静止表示します。

## 本文の書き方と日本語

本文と速さは `src/config/typewriter.js` で変更します。1行が1ブロックです。

| 書き方 | 打ち方 |
|---|---|
| `# 見出し` | Tabキーで中央へ送り、太字（重ね打ち）で打つ |
| `## 見出し` | 左揃えの太字 |
| `---` | ハイフンを1行ぶん連打する区切り線（1打0.4打鍵分の速さ） |
| 空行 | 改行レバーで1行送る |
| `・項目` / `- 項目` | 箇条書き。折り返した行はTabで項目の文頭にそろえる |
| それ以外 | 段落。紙の幅で折り返す。行頭の全角スペースは字下げ |

全角文字は和文タイプライターと同じく、1文字ごとに1em（字間なし）進みます。英数字は0.6emです。1行は英数字36字分（日本語は約21字）、スマートフォンでは22字分（日本語は約13字）です。日本語は明朝体（Hiragino Mincho / Yu Mincho / Noto Serif JP）で印字します。折り返しでは英単語を分割しません。日本語は禁則処理を行い、「、。」」などを行頭に、「「（」などを行末に置きません。

英文キーボードには仮名・漢字のキーがありません。そのため、キーがない文字は文字コードから決まる英字キーを代わりに押します。同じ文字は常に同じキーです。英字の大文字は反対の手側のShiftを押します。

ページには、同じ本文を見出し・区切り線・段落の構造で、視覚的に隠したテキストとしても出力しています（読み上げ・検索用）。

## ページに続きのセクションを追加する

`src/pages/index.astro` の `<TypewriterIntro />` の後ろにセクションを置きます。ScrollTriggerのpin解除後に、通常のページとしてそのまま続けられます。この版には後続の仮コンテンツを置いていません。

同じページにSVGを複数配置する場合は、SVGのIDと `url(#...)` 参照にも個体別の接頭辞を付けてください。現在の構成は1台の表示を前提としています。
